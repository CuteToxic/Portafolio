# Martin · Soluciones web para negocios

Portafolio personal con tres proyectos de demostración, construido con HTML, CSS y JavaScript sin dependencias.

## Proyectos

- **Mesa Criolla:** carta por categorías, carrito, recojo o delivery y resumen para copiar.
- **Barrio Barber:** solicitud guiada con servicio, barbero, fecha, horario y resumen.
- **Punto Técnico:** ficha de consulta con servicio, equipo, descripción de falla y modalidad de atención.

Las marcas y los datos de las demos son ficticios. Las demos no procesan pagos, no envían pedidos ni confirman citas.

## Uso local

Abre `index.html` en un navegador. También puedes servir esta carpeta con cualquier servidor HTTP estático.

## Contacto

La página principal contiene enlaces a WhatsApp y Gmail, y un botón para copiar el correo. El formulario prepara un mensaje para que el visitante lo revise y lo abra en WhatsApp. No hay servidor de formularios ni base de datos.

## GitHub Pages

La raíz del repositorio contiene `index.html`. Para usar GitHub Pages, selecciona la rama principal y la carpeta raíz en Settings → Pages. Los enlaces a las demos son relativos y funcionan en una subcarpeta de proyecto.
